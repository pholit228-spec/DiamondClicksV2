# DiamondClicks

Geode-мод для Geometry Dash (2.2081). Автор: **diamondsoup**.

Пока ты зажимаешь кнопку прыжка, каждый кадр считается кликом (как автокликер), а не одним длинным нажатием.

## Настройки (в игре: Geode → моды → DiamondClicks)

- **Enabled** — вкл/выкл мод (выкл = обычное зажатие как в ванили).
- **Click delay (frames)** — задержка между кликами при зажатии, в кадрах (физических тиках).
  - `1` — свежий клик на каждом кадре (отпустить + нажать).
  - `2+` — короткий тап раз в N кадров.
- **Mode: Cube / Ship / Ball / UFO / Wave / Robot / Spider / Swing** — на каких режимах работает автоклик. Например, оставь включёнными только Wave и Ship.

Примечание: на ship и wave при задержке `1` клик «отпустить + нажать» в одном кадре в итоге даёт зажатое состояние. Если нужен заметный автоклик на них, поставь задержку `2` и больше.

## Как собрать (GitHub Workflows)

```bash
git init
git add .
git commit -m "DiamondClicks"
git branch -M main
gh repo create DiamondClicks --public --source=. --push
```

Дальше открой вкладку **Actions** в репозитории, дождись зелёной сборки и скачай артефакт **Build Output** — внутри файл `.geode` (одним файлом для Windows, macOS, iOS и Android).
Положи его в папку `geode/mods`.

Если сборка падает на версии Geode, проверь строку `"geode"` в `mod.json` — она должна совпадать с версией SDK (workflow подставляет последнюю сама).
